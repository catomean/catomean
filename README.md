### How I work

- **One `verify` command per repo** — lint, typecheck, test. CI runs exactly that. Green
  locally means green on the branch.
- **Self-hosted by default.** Hetzner, Caddy, systemd, Postgres. No vendor lock-in, no
  per-seat pricing, no surprise bill.
- **Everything ships through a branch and CI.** The deliberate step is the pipeline, not a
  person clicking a button.
- **Built to hand over.** Documentation, backup restores, and runbooks included.
- TypeScript · Next.js · Postgres · Drizzle/Prisma · Tailwind · GitHub Actions

### Extracted libraries & open source

**[ai-forms](https://github.com/bitbaum/ai-forms)** — fill a form from one sentence, then
keep talking to it until it is right. The hard part is not the first fill, it is that
*"actually, make it urgent"* has to patch the form instead of wiping it. Headless,
provider-agnostic, no markup, no styles. [`npm`](https://www.npmjs.com/package/ai-forms)

**[crewless](https://github.com/bitbaum/crewless)** — the harness that lets one person run
production fleets: nobody merges by hand, deploys and npm publishes are reconcilers, and
every repo has exactly one definition of "verified". Extracted from live operations, outage
reports preserved in the script headers. Being built in public, numbers included — starting
from one star: [the experiment's opening entry](https://orangecat.ch/articles/one-star-c4w71w).

**[threadkit](https://www.npmjs.com/package/threadkit)** · **[bip-kit](https://www.npmjs.com/package/bip-kit)** —
each extracted from a production system above, none invented for its own sake. All published
tokenless via OIDC trusted publishing.
